# 도각도각 공개 페이지

기계식 키보드 타건음을 내는 iOS 커스텀 키보드 앱 **도각도각**(Dogak Dogak)의 개인정보처리방침과 지원 페이지입니다. GitHub Pages로 게시하며, App Store에 등록한 개인정보처리방침 URL과 지원 URL이 이 사이트를 가리킵니다.

앱 소스 코드는 이 레포에 없습니다.

## 구조

- `main` 브랜치 루트를 GitHub Pages가 Jekyll로 빌드합니다. 별도 테마나 레이아웃 파일은 없습니다.
- 각 페이지 주소는 front matter의 `permalink`로 정합니다. App Store에 등록된 주소라서 바꾸면 안 됩니다.
- 이 README는 `_config.yml`의 `exclude`로 사이트 빌드에서 뺍니다.

## 처리방침을 고칠 때

- 한국어판(`privacy.md`)과 영문판(`en/privacy.md`)의 내용을 함께 맞춥니다.
- 맨 위의 시행일을 갱신합니다. 사용자에게 불리하게 바뀌는 경우에는 시행 전에 앱 안에서 미리 알립니다(처리방침 11항).
- 수집 항목이 바뀌면 App Store Connect의 개인정보 라벨도 같이 고칩니다.
